現実的なシナリオ、完成したアプリケーション、共有バックログを使い、ソフトウェア開発ライフサイクル全体で GitHub Copilot を体験します。変更を計画し、コードを作成し、動作をテストし、プルリクエストをレビューし、エージェントと作業を管理します。

## シナリオ

ボードゲーム開発をテーマにしたクラウドファンディングを提供する架空の企業、Tailspin Toys に新しく加わった開発者として作業します。チームのバックログは GitHub の Issue として登録済みで、すぐに取り組めます。バックログには、フィルターやページネーションなどの機能開発と、アクセシビリティやコーディング標準などの品質改善が含まれています。

## 作業環境を選ぶ

GitHub Copilot は、普段の作業環境で利用できます。好みの開発方法に合った環境を選んでください。各ワークショップには独自のセットアップがあり、共通の Tailspin Toys シナリオを使います。

### [GitHub Copilot CLI][cli]

ターミナルでエージェント型アシスタントを使います。Plan モードと Autopilot モード、命令、スキル、カスタム エージェント、Playwright MCP、Agent Merge、実用的なスラッシュ コマンドを扱います。

### [GitHub Copilot app][app]

エージェント セッションを並行して実行し、セッション モードを切り替え、Canvas で共同作業し、デスクトップ アプリから GitHub の Issue とプルリクエストを管理します。

### [GitHub Copilot cloud agent][cloud]

GitHub の Issue を非同期エージェントに割り当て、作業を案内し、進行状況を確認し、エージェントが作成したプルリクエストをレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使います。エディターを離れずに、Copilot Chat の agent mode、MCP サーバー、カスタム エージェントを扱います。
