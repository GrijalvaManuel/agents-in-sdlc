使用真实场景、完整应用和共享待办事项，探索 GitHub Copilot 在软件开发生命周期中的应用。你将通过迭代规划更改、编写代码、测试行为、审查拉取请求并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为带有开发者主题的棋盘游戏提供众筹服务。团队的待办事项已创建为 GitHub 议题，供你开始处理。其中包括筛选和分页等功能开发，以及无障碍和编码标准等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择符合你构建习惯的环境。每个工作坊都有自己的设置流程，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。学习 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行代理会话、切换会话模式、使用画布协作，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云端代理][cloud]

将 GitHub 议题分配给异步代理、引导其工作、监控进度并审阅它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。借助 Copilot Chat 智能体模式、MCP 服务器和自定义代理，无需离开编辑器即可完成工作。
